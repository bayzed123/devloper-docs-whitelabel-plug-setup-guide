# LKS Attire: Features

## Storefront

Bilingual fashion storefront, search/category/product/cart/checkout, guest checkout, accounts, tracking, wishlist, reviews, size guide, variants, stock, discounts, coupons, Bangladesh addresses and zones, invoices, admin operations, SEO/sitemap/structured data, PWA, and brand-configurable themes.

## Client handoff

Before presenting the project to a client, replace sample catalog records, imagery, prices, stock, contact information, delivery policy, payment instructions, legal pages, and analytics identifiers. Mark any provider integration as **not configured** until a sandbox or test transaction has succeeded.
