# Babyshop: Features

## Storefront

Bilingual baby-and-kids storefront, search/filter, product variants, cart, guest checkout, delivery zones, coupons, referrals, gift wrap, OTP, order tracking, invoices, accounts, wishlists, registries, returns, reminders, gift finder, inventory, reviews, back-in-stock, admin, PWA shell, courier hooks, analytics, messaging, push, Turnstile, backups, and scheduled jobs.

## Client handoff

Before presenting the project to a client, replace sample catalog records, imagery, prices, stock, contact information, delivery policy, payment instructions, legal pages, and analytics identifiers. Mark any provider integration as **not configured** until a sandbox or test transaction has succeeded.
