# Jewellery and Fashion: Features

## Storefront

Bilingual jewellery storefront/PWA, search/filter, collections and sets, gift finder, guest checkout, delivery fees, coupons, referrals, gift wrap, OTP/Turnstile hooks, abandoned-checkout recovery, accounts, addresses, wishlists, registries, returns, invoices, order tracking, admin inventory and roles, and optional payment/courier/notification integrations.

## Client handoff

Before presenting the project to a client, replace sample catalog records, imagery, prices, stock, contact information, delivery policy, payment instructions, legal pages, and analytics identifiers. Mark any provider integration as **not configured** until a sandbox or test transaction has succeeded.
