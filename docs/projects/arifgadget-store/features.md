# Arif Gadget Store: Features

## Storefront

Wholesale gadget catalog, search/filter/sort, categories, product details, reviews, volume pricing, MOQ, cart, server-side stock/pricing checks, checkout, postcode delivery lookup, order tracking, invoices, WhatsApp handoff, accounts, history, wishlist, admin inventory/orders/reviews/staff/settings/analytics, and optional courier, Google, AI, email, and Meta integrations.

## Client handoff

Before presenting the project to a client, replace sample catalog records, imagery, prices, stock, contact information, delivery policy, payment instructions, legal pages, and analytics identifiers. Mark any provider integration as **not configured** until a sandbox or test transaction has succeeded.
