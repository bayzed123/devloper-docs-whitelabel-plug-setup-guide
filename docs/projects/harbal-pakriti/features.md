# Harbal Pakriti: Features

## Storefront

Bangla-first herbal storefront, kits and kit builder, collections, journal, accounts, wishlist, reviews, referrals, guest checkout, delivery fees, COD/manual bKash-Nagad-Rocket, optional bKash/SSLCommerz, order tracking, invoices, inventory batches, expiry, returns, reports, staff roles, certification badges, and claims checks.

## Client handoff

Before presenting the project to a client, replace sample catalog records, imagery, prices, stock, contact information, delivery policy, payment instructions, legal pages, and analytics identifiers. Mark any provider integration as **not configured** until a sandbox or test transaction has succeeded.
